# Filter & Form — A Product Design Ritual

A responsive, interactive website that uses the steps of making South Indian filter coffee as a metaphor for the product design process.

## Run locally in VS Code

1. Download and unzip `filter-coffee-product-design.zip`.
2. Open the unzipped `filter-coffee-product-design` folder in VS Code (`File → Open Folder…`).
3. Open `index.html` in your browser.

**Recommended:** install the **Live Server** extension in VS Code, then right-click `index.html` and choose **Open with Live Server**. This gives you automatic refresh when you edit files.

No build tools, npm install, or framework setup required. Google Fonts are loaded online; the site still works with fallback fonts if offline.

## Project structure

- `index.html` — page content and semantic structure
- `styles.css` — layout, color palette, responsive styling, illustrations
- `script.js` — interactive six-step journey and progress indicator

## Customize it

- Change the six step descriptions and design metaphors in `script.js`.
- Adjust the coffee palette at the top of `styles.css` in `:root`.
- Edit headings, field notes, and footer content in `index.html`.

## The six-step metaphor

1. Choose your beans → Discover
2. Grind & measure → Define
3. Pack the filter → Ideate
4. Let it drip → Prototype
5. Mix & taste → Test & iterate
6. Serve the good stuff → Deliver
