# Filter & Form — connected website

This folder contains both website concepts:
- `index.html` — the interactive, hands-on coffee-making game.
- `first-idea/index.html` — the original editorial-style site with the headline **“Good things take filtering.”**

## Open in VS Code
1. Extract the ZIP.
2. Open the `filter-coffee-game` folder in VS Code.
3. Open `index.html` with Live Server.

Clicking the FILTER AND FORM brand in the game opens the original “Good things take filtering” website. Its brand link returns to the game. The brand text is explicitly styled coffee brown for normal, visited, hover, and active states.
